8. BUILD SPIRAL STAIRCASES:

9. ADD PORTAL + LINTAL + ORB at TOP_Y + {0.3, 1.3, 2.8, 3.6}

### 2.2 Animation Loop (`animate()`)

```
FUNCTION animate():
  requestAnimationFrame(animate)                     // Schedule next frame

  dt = min(clock.getDelta(), 0.05)                   // Clamp delta (≤50ms)
  t = clock.elapsedTime                                // Elapsed time since start

  ── Camera ──────────────────────────────────────────────
  controls.autoRotate = params.autoRotate
  controls.autoRotateSpeed = params.rotationSpeed
  controls.update()                                    // Apply damping + rotation

  ── Scene parameters ────────────────────────────────────
  scene.fog.density = params.fogDensity
  renderer.toneMappingExposure = params.exposure
  sun.intensity = params.moonlight + sin(t * 0.13) * 0.08

  ── Portal + Orb pulse (surge-responsive) ────────────────
  surge *= exp(-dt * 1.6)                              // Exponential decay
  pulse = 0.5 + 0.5 * sin(t * pulseSpeed * 2)          // Triangle wave 0..1
  orb.emissiveIntensity = (0.7 + pulse*0.9 + surge*2.2) * orbPower
  portal.emissiveIntensity = 0.35 + pulse*0.25 + surge
  portalLight.intensity = (6 + sin(t*2.1)*4 + surge*22) * orbPower

  ── Torch flicker ────────────────────────────────────────
  FOR each torch i:
    flux = torchFlux * (0.75 + sin(t*9 + phase)*0.45 + sin(t*23 + phase*3)*0.2)
    light.intensity = 15 * flux
    flame.scale.y = 1.75 * (0.85 + 0.3 * clamp(flux, 0, 2))
    halo.opacity = clamp(0.45 + 0.4*flux, 0, 1)

  ── Ember particle update ────────────────────────────────
  FOR each EmberField:
    update(dt, t, wind + sin(t)*0.15, emberFlow)
    ── Per particle: ──
      life += dt * (0.55 + flow*0.8)
      IF life ≥ max: respawn (reset position, velocity, lifetime)
      k = life/max
      vel.y += 0.55 * dt                              // Gravity
      vel.x += (wind*0.7 + sin(t*3.1 + idx)*0.5) * dt // Horizontal drift
      pos += vel * dt
      fade = pow(1-k, 1.5) * (0.6 + 0.4*sin(t*14 + idx))
      color = base_color * fade

  ── Bloom + render ───────────────────────────────────────
  bloom.strength = params.bloomStrength + surge * 0.25
  composer.render()                                   // RenderPass → Bloom → OutputPass
  stats.update()

  ── Veil fade (one-time) ─────────────────────────────────
  IF not veilDone:
    veil.classList.add('gone')                        // Triggers CSS opacity fade
    veilDone = true

  ── Telemetry (every 0.2s) ─────────────────────────────
  acc += dt
  IF acc > 0.2:
    acc = 0
    fps = smoothed (1/dt)
    live_embers = sum of all active embers
    azimuth = atan2(cam.x - center.x, cam.z - center.z) in degrees
    Update telemetry HUD elements

END FUNCTION
```

## 7. Mathematical Notes

- **Ziggurat layout**: Level 0 has 15×15=225 cubes, level 6 has 3×3=9. Total = 225+121+81+49+25+9+1 = 511. Plus 7×4=28 corner pillars = 539. With random perturbation edges: ~671 instances.
- **Spiral parametrics**: `angle = k*π/2 + 0.35 + t*π*0.9` creates outward spiral from base to TOP_Y.
- **HSL color gradient**: `hsl(0.075 + rand(-0.014, 0.014), rand(0.14, 0.25), 0.15..0.55)` creates stone-like variation.
- **Ember fade curve**: `pow(1-k, 1.5)` gives a smooth fade-out as particles age.
- **Azimuth calculation**: `atan2(cam_x - center_x, cam_z - center_z)` in degrees, normalized to 0-360°.
